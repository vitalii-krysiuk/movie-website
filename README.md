# movie-website
Movie Website

Das ist ein kleines Webprojekt, das ich mit HTML, CSS und JavaScript gemacht habe.
Bei diesem Projekt habe ich eine einfache Website erstellt, auf der man Filme nach verschiedenen Kategorien anschauen kann.

Was kann die Website?
 - Filme nach Kategorien anzeigen
 - Zwischen Action, Drama und Comedy wechseln
 - Einen Film zufällig empfehlen lassen

Verwendete Technologien
HTML
CSS
JavaScript

Über das Projekt
Bei diesem Projekt habe ich vor allem mit HTML und CSS gearbeitet. 
JavaScript habe ich benutzt, um zwischen den Kategorien zu wechseln und eine zufällige Filmempfehlung anzuzeigen.
Das Projekt war für mich eine Übung, um mehr Erfahrung mit JavaScript und der Arbeit mit verschiedenen Elementen auf einer Website zu sammeln.
